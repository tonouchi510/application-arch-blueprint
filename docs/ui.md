# 画面設計（サークル一覧 / サークル / ユーザー設定）

`frontend/app`（Flutterアプリ）の画面構成。サークル一覧・サークル・ユーザー設定の3画面を実装済み。

## ナビゲーション

```
/signin, /signup（既存）
/settings  UserSettingsRoute（authGuard付き、独立ルート）
HomeRoute（AppBar + Drawer のシェル）
  ├─ CircleListRoute（初期表示）
  └─ CircleDetailRoute (:circleId)
```

Drawerは「サークル一覧」「ユーザー設定」の2項目。

## サークル一覧ページ

「参加中のサークル」「サークルを探す」の2タブ + サークル名検索。

- **参加中**: 自分がオーナー or メンバーのサークル。行タップでサークルページへ。オーナーなら`⋮`から削除可。
- **探す**: 全サークル。誰でも参加可能で、未参加サークルには「参加」ボタン（満員時のみdisabled）。
- 右下の＋FAB（`premium`/`admin`ロールのみ表示）でサークル作成。

## サークルページ

4タブ構成（権限タブはオーナーのみ表示）。

- **概要**: 名前・説明（オーナーは編集可）、メンバー数、オーナー名
- **メンバー**: メンバー一覧（表示名で表示）。オーナーはユーザーID指定で追加、他メンバーへのオーナー権限委譲が可能。自分の行のみ「退会」ボタンあり（他人の削除機能はなし）
- **権限**（オーナーのみ）: 「メンバーによる掲示板作成を許可」のON/OFFのみ
- **掲示板**: 掲示板一覧 → 選択すると投稿スレッド展開。オーナー、または掲示板作成が許可されたメンバーが作成可。投稿は最大100件、作成者のみトピック編集・ステータス変更可

## ユーザー設定ページ

- 表示名・電話番号・プロフィール画像URLを編集（メールアドレスは対象外）
- プランはロール（custom claims）を読み取り専用表示
- 退会（確認ダイアログ→アカウント削除→サインアウト）
